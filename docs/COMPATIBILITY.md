# Compatibility

## Baseline

- Target game: **Pokémon Red**
- Platform: **Gen1Recomp**
- Cartridge: **G1R Deluxe — Red / Roddsoft Edition**

## Policy

Before enabling a mod:

1. Confirm it targets Red or an applicable Gen 1 target.
2. Record hard and optional dependencies.
3. Check overlapping registry/data writes, hooks, events, assets, and UI changes.
4. Define deterministic load order where coexistence is valid.
5. Prefer an integration patch over modifying upstream code.
6. Validate and test the combined cartridge after every addition.
