## Intake rules

For every mod added, record its exact upstream source, pinned version/commit, license/redistribution status, dependencies, load-order requirements, and any local changes.

Prefer keeping upstream code unchanged. Put cartridge-specific integration changes in `patches/` or a clearly identified local integration mod.
